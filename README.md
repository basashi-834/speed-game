# スピード(トランプゲーム)

**制作者：** **

ブラウザで遊べるトランプゲーム「スピード」です。プレイヤー対 CPU の1対1で、手札を場札にどんどん出していき、先に手札と山札をすべて出し切ったほうが勝ちです。

HTML / CSS / JavaScript だけで作っています(フレームワーク・ライブラリは使っていません)。

## 遊び方

1. `index.html` をブラウザで開きます(VS Code の Live Server などで開くのがおすすめです)
2. 難易度ボタン(easy / normal / hard)を押すとゲームが始まります
3. 5秒のカウントダウンのあと、ゲームスタートです
4. 自分の手札をドラッグして、場札(FIELD)の上で離すとカードを出せます

## ルール

- 場札と**数字が1つ違う**カードを出せます(例: 場札が 7 なら 6 か 8)
- **1 と 13 はつながっています**(場札が 13 なら 1 も出せます)
- 手札は最大4枚です。出すと山札から自動で補充されます
- 補充したカードが手札と同じ数字なら、手札に重なります(影が付いて表示されます)
- 手札と山札をすべて出し切ったほうの勝ちです

### お互いに出せなくなったとき

| 状況                                             | どうなるか                                                                                                                     |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| どちらも出せるカードがなく、山札が残っている     | 「山札をドラッグしよう」と表示されます。自分の山札を右の場札にドラッグすると、CPU も山札から1枚を左の場札に出して再開します    |
| どちらも出せるカードがなく、山札も両方なくなった | 「手札をドラッグしよう」と表示されます。手札を右の場札に好きに出せます。同時に CPU も手札からランダムに1枚、左の場札に出します |

### 難易度

難易度によって、CPU がカードを出すまでの待ち時間が変わります。

| 難易度 | CPU の待ち時間 |
| ------ | -------------- |
| easy   | 2.0 〜 3.0 秒  |
| normal | 1.5 〜 1.7 秒  |
| hard   | 0.7 〜 1.0 秒  |

## 主な機能

- ドラッグ&ドロップでカードを出す(HTML Drag and Drop API)
- CPU の自動プレイ(難易度別の待ち時間)
- ゲーム開始前のカウントダウン(5 → 1 → スタート！)
- お互いに出せないときの救済処理(山札ドラッグ / 手札の自由出し)
- 勝敗判定
- アニメーション
  - カードを置いたときの「置いた感」の動き
  - 置けない場所に落としたときの揺れ
- カードの枠は動かず、カードだけがアニメーションする(枠とカードを別の要素に分けています)
- 空の置き場もカード型の枠で表示
- ゲーム中は難易度ボタンを非表示にし、決着後に再表示
- レスポンシブ対応(スマホでも手札4枚が1列に収まる)

## 画面サイズ

ブレークポイントは **1130px** です。

| 画面幅                  | カード本体    | 手札同士の隙間 |
| ----------------------- | ------------- | -------------- |
| 1131px 以上(PC)         | 192px × 264px | 8px            |
| 1130px 以下(スマホなど) | 65px × 90px   | 4px            |

1130px は「カード1枚が取る幅 216px × 5枚 + 隙間 32px = 1112px」に、スクロールバーぶんの余裕を足した数字です。スマホ側は、幅 375px の画面で手札4枚が1列に収まるように計算しています。

## 既知の課題

- `img/back.png` がまだないため、山札の裏面が灰色で表示され、コンソールに 404 エラーが出ます
- 重なった手札(同じ数字が2枚以上)を出すと、重なっていた分もまとめて消えます
